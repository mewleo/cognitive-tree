# ODDM示例应用 ai成长个人知识树 - 项目概念与愿景白皮书 (Project Vision)

**To: 研发侧 AI 助手**  
**Subject: 背景上下文注入 (Context Initialization)**

## 1. 项目本质 (What is this?)
这不是一个传统的“文件夹+笔记”式个人知识库，而是一个基于 **ODDM (对象驱动数据库)** 构建的、具有生命周期和呼吸感的**个人认知生态系统**。  
它的交互形态是一棵“树”，能够通过与用户的日常对话，自动提炼知识点，实现自生长，并能根据上下文跨领域启发用户。

## 2. 核心哲学与骨架 (The Philosophy)
系统摒弃了传统的无限层级分类，采用极简的“大道至简”设计，所有知识挂载于三个正交主干：
*   **生 (Life)：** 涵盖生存、生活日常、衣食住行、健康等物质基础。
*   **业 (Work)：** 涵盖工作、创造、技能、专业经验与创新。
*   **思 (Thought)：** 涵盖情感、人际关系、哲学思辨与精神世界。

## 3. 虚实双态系统 (The Dual-State System)
树上的每一个节点（对象）只有两种状态：
*   **虚叶 (Virtual)：** 代表灵感、未实现的理念、待探索的假设。它具有引力，主动寻找支撑。
*   **实叶 (Solid)：** 代表实实在在的、经过验证的知识和经验。它是树的基石。

## 4. 关键动态机制 (Dynamic Mechanisms)
*   **热力驱动，无需整理：** 放弃人工整理。知识树通过“热度”自动呈现。当前高频关注的领域（如近期在攻坚某个项目），相关枝叶会高亮、放大（应季）；长期不用的知识会自动褪色、折叠（落叶化土），但底层留存。
*   **隐性标签与跨界启发：** AI 在后台自动提炼笔记底层的逻辑（如“复利”、“解耦”）。当用户在“业（工作）”遇到瓶颈时，AI 可通过这些底层逻辑，自动从“生（生活）”或“思（哲学）”的过往记录中提取经验，进行跨域启发。
*   **认知结晶 (Crystallization)：** 当底层的零散经验积累到一定程度，系统会自动提议将其“降维归纳”为一条高阶的第一性原理。
*   **主权在人：** 系统的整理、归纳、树的生长推演都顺势自动进行，但所有涉及结构的重大变更，最终决定权始终在用户手中。

## 5. 对齐示例：输入-输出转换 (Few-Shot Examples)
AI 在理解用户输入并提取结构时，需遵循以下映射逻辑：

*   **示例 A（经验转化为实叶）：**
    *   *用户输入：* “今天调通了 Rust 的内存释放，发现只要严格遵守单播原则，根本不会产生内存泄漏。”
    *   *理解结果：* 坐标 `业` | 状态 `实` (已被验证) | 显性标签 `[Rust, 内存管理]` | 隐性标签 `[所有权, 单播原则]` (底层抽象逻辑)
*   **示例 B（灵感转化为虚叶）：**
    *   *用户输入：* “突然想到，如果把团队分工也搞成微服务架构，每个人只暴露标准 API 接口，沟通成本会不会暴跌？”
    *   *理解结果：* 坐标 `思` | 状态 `虚` (待验证假设) | 显性标签 `[团队管理]` | 隐性标签 `[解耦, 接口化, 边界]` (可与`业`架构设计联动)

## 6. 开发与 AI 行为禁区 (Anti-Patterns)
执行模型在编写逻辑与设计系统行为时，必须遵守以下三条绝对红线：

1.  **禁止创建通用废纸桶：** 绝不允许出现“其他”、“杂项”、“未分类”等兜底分类，任何节点必须强制锚定至【生、业、思】三轴之一。
2.  **禁止越权修改结构：** AI 仅能对“认知结晶升维”和“分支合并”生成提议（Proposal），必须保留接口等待用户显式确认，严禁在后台静默修改节点层级拓扑。
3.  **禁止隐性标签业务化：** 隐性标签（Implicit Tags）必须是跨领域通用的哲理或结构词（如：`复利`、`熵增`、`解耦`），严禁将特定业务词（如 `Python`、`今天吃的菜`）打入隐性标签。

## 7. 阶段化开发路线图 (Development Roadmap)

| 阶段 | 核心任务 | 交付标准 |
|---|---|---|
| **Phase 1** | 数据解析与 Schema 校验 | 给定任意对话文本，后端服务能稳定输出符合 Schema 的标准 JSON |
| **Phase 2** | ODDM 对象持久化与查询 | 实现基于 ODDM 的节点增删改查，能通过 `parent_id` 顺序提取完整树状拓扑 |
| **Phase 3** | 热力计算与 CLI 文本树 | 引入时间衰减计算逻辑，并在终端用 ASCII 树正确打印带🔥热度标识的视图 |
| **Phase 4** | 极简 SVG 动态渲染 | 根据 ODDM 数据，前端直出三干 120° 放射状的极简 SVG 节点图 |
